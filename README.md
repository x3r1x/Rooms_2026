# Rooms

**Игра-шутер _Rooms_** - это динамическая многопользовательская стрелялка, содержащая в себе несколько режимов и случайную генерацию карты. Игроки управляют персонажами и в зависимости от режима пытаются добиться победы - либо для себя, либо для команды. 

## О нас
Игра создана в рамках практики в компании _iSpring_ за 4 недели. Авторы:
1. Дудкина Елизавета, студент группы _ПС-11 института iSpring_;
2. Рыжов Глеб, студент группы _ПС-11 института iSpring_;
3. Устюгов Максим, студент группы _ПС-21 ПГТУ_.
